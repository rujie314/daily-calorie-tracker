# CalorieNote · 每日飲食熱量計算工具

一個專為台灣常見飲食打造的每日熱量紀錄與自動估算網頁工具。支援輸入**食物名稱**、**上傳/貼上食物照片**、**份量**與**餐別（早餐／午餐／晚餐／點心）**，自動估算大卡並即時統計各餐與整天總攝取熱量。

## 主要功能

- **四餐分類與即時加總**：分別統計 `早餐`、`午餐`、`晚餐`、`點心` 的總熱量與佔比，並於儀表板顯示整天總攝取熱量、剩餘可用熱量與蛋白質／碳水／脂肪合計。
- **智慧食物與份量估算引擎**：內建 90+ 項台灣常見早午晚餐、便當、麵食、水果與手搖飲資料庫，支援自動完成搜尋，並能解析 `半碗`、`2顆`、`150g`、`大杯`、`微糖`、`無糖`、`少飯`、`去皮` 等份量與客製詞彙；未收錄的食物也會依關鍵字自動估算。
- **食物照片上傳與 AI 辨識（選填）**：支援點擊上傳、拖曳或 `Ctrl+V` 直接貼上照片並自動壓縮儲存於本地 SQLite；若在右上角「目標與 AI 設定」填入 Gemini API Key（或設定環境變數 `GEMINI_API_KEY`），即可一鍵從照片自動辨識食物品項、份量與大卡。
- **歷史趨勢與匯出**：支援任意日期切換、近 7 日熱量長條圖、BMR/TDEE 每日目標試算，以及匯出 UTF-8 CSV 報表。

## 啟動方式

本工具使用 Python 標準函式庫與原生瀏覽器 ES Modules，**無需安裝任何第三方套件**：

```bash
python server.py
```

啟動後請開啟瀏覽器前往：`http://127.0.0.1:8765`

> 若要修改預設埠號，可設定環境變數 `PORT=8080 python server.py`。
